# 10 project

## 민들레 농장 (`farm-game/`)

브라우저에서 바로 돌아가는 픽셀 농장 생활 게임이에요. 스타듀 밸리처럼 하고 싶은 걸 골라서 하며 지내는 게임이에요.

- **실행:** `farm-game/index.html`을 브라우저로 열면 돼요. 설치할 것은 없어요.
- **할 수 있는 것:** 밭 갈기, 심기, 물 주기, 수확, 출하, 낚시, 채석장 채굴, 벌목, 제작(울타리·돌길·횃불·화분·벤치·스프링클러), 원하는 곳에 놓아 농장 꾸미기, 마을 사람과 대화하고 선물하기, 사계절, 날씨, 밤낮 순환, 자동 저장
- **조작:** WASD 이동, Space 도구 사용, E 행동, 1~= 도구 선택, I 가방·제작, H 도움말 (휴대폰은 화면 조이스틱과 버튼)
